# Data model: 001

All tables live in PostgreSQL schema `public`. Ids are `uuid` (v7, generated by the app). Timestamps are `timestamptz` in UTC.

## User
| Field | Type | Rules |
|---|---|---|
| Id | uuid | PK |
| Email | text | normalized (trimmed, lower-cased), unique, ≤ 254 chars |
| DisplayName | text? | 1–40 chars after trim. Null until the profile is completed |
| Locale | text | one of `en`,`fr`,`ar`,`es`, default from the sign-in locale |
| CreatedAt / LastSeenAt | timestamptz | |

`ProfileCompleted` ⇔ `DisplayName IS NOT NULL`.

## OtpChallenge
| Field | Type | Rules |
|---|---|---|
| Id | uuid | PK |
| Email | text | normalized, indexed `(Email, CreatedAt desc)` |
| CodeHash | bytea(32) | HMAC-SHA256(pepper, email + ":" + code) |
| Locale | text | locale used for the email |
| CreatedAt / ExpiresAt | timestamptz | ExpiresAt = CreatedAt + 10 min |
| Attempts | int | 0..5 |
| ConsumedAt / SupersededAt | timestamptz? | |
| RequestIpHash | bytea(32) | HMAC of the IP (audit only) |
| xmin | concurrency token | |

State: `Active` → `Consumed` | `Superseded` | `Exhausted` (Attempts = 5) | `Expired` (now > ExpiresAt). Only `Active` can be verified. Rows older than 24 h are purged by a background job.

## UserSession
| Field | Type | Rules |
|---|---|---|
| Id | uuid | PK, stored in the auth cookie as claim `sid` |
| UserId | uuid | FK → User, cascade delete |
| CreatedAt / LastSeenAt / ExpiresAt | timestamptz | sliding 30 days |
| RevokedAt | timestamptz? | set by sign-out or sign-out-everywhere |
| UserAgent | text | truncated to 200 chars, for a future "your devices" list |

A session is valid ⇔ `RevokedAt IS NULL AND ExpiresAt > now`.

## AuditEvent
| Field | Type | Rules |
|---|---|---|
| Id | bigint identity | PK |
| Type | text | `otp.requested`, `otp.rate_limited`, `otp.verify_failed`, `auth.signed_in`, `auth.signed_up`, `auth.signed_out`, `auth.signed_out_everywhere`, `profile.updated` |
| At | timestamptz | indexed |
| UserId | uuid? | |
| EmailHash | bytea(32)? | HMAC(pepper, email) |
| IpHash | bytea(32)? | |
| Detail | jsonb? | no secrets, no raw email |

## EmailOutbox
| Field | Type | Rules |
|---|---|---|
| Id | uuid | PK |
| To | text | recipient. Row deleted after it is sent |
| Template | text | `otp-code` |
| Locale | text | |
| PayloadProtected | text | template parameters, encrypted with Data Protection (contains the code) |
| CreatedAt / NextAttemptAt | timestamptz | |
| Attempts | int | max 3, then dead-lettered (`FailedAt`) |
| FailedAt | timestamptz? | |

## DataProtectionKeys
The standard `Microsoft.AspNetCore.DataProtection.EntityFrameworkCore` table.

## Spark (read-only, file-backed in 001)
Loaded at startup from `content/fun/{lang}.json`: `lang`, `kind`, `tags[]`, `text`, with a stable id = index within the file. Feature 002 moves sparks into the DB (#15).
